### 2. 模型集成优化 ✅

**动机**：三个有效实验的 AUC 高度一致（0.914~0.919），说明单模型区分能力已达天花板。

| 方案 | acc | 恶性召回 | AUC |
|------|-----|---------|-----|
| 单模型 v2（R50/224）| 84.98% | 88.98% | 0.9163 |
| 单模型 vE（R101/288）| 84.98% | 86.44% | 0.9186 |
| **集成（2模型，@0.51）** | **85.45%** | 87.29% | **0.9287** |
| 集成 @0.50（错误阈值）| 84.51% | — | 0.9287 |
| 集成 + TTA | 83.57% | 84.75% | 0.9242 |

**★ 关键发现：集成必须重新确定阈值**
```
集成 @0.50 → 84.51%（低于单模型）
集成 @0.51 → 85.45%（高于单模型）
原因：概率平均后分布更集中，0.5 不再是最优分割点
```

**TTA 为何有害**：皮肤镜是圆形视野设备，图像有方向性；垂直翻转/旋转破坏解剖方位感。

**集成的真实价值**：
- AUC +1.24pp（0.9163 → 0.9287）——区分能力实质增强
- 筛查模式漏诊率从 4.24% 降至 **3.39%**

### 3. 后端双模型接入 ✅

**架构**：
```
输入图片
   ↓
Predictor（集成，主）
   ├─ models_v2_full (R50/224)
   └─ models_vE_r101_288 (R101/288)
   → 良性/恶性 + 置信度（acc 85.45%）
   ↓
TypeClassifier（7类，辅）
   └─ models_compressed_7class/model_int8.onnx
   → Top3 类型 + 分组汇总（acc 70.49% ONNX）
```

**新增配置开关**（`backend/app/config.py`）：
```python
ENABLE_ENSEMBLE = True            # 集成推理（默认开）
ENSEMBLE_MODELS = [...]           # 集成员
ENSEMBLE_THRESHOLD = 0.51         # 集成推荐阈值

ENABLE_TYPE_PREDICT = True        # 7类推理（默认开）
TYPE_USE_ONNX = True              # 7类走ONNX加速
TYPE_ONNX_PATH = ...              # 7类ONNX路径
```

**新增接口**：
| 接口 | 说明 |
|------|------|
| `GET /api/model/types` | 7 类定义（编码/中文名/分组/说明）|
| `GET /api/model/info` | 扩展：含 `type_model` 状态 |
| `POST /api/predict` | 响应新增 `type_reference` 字段 |

**降级机制**：
- 集成成员不足 2 个 → 自动回退单模型
- 7 类加载失败 → 主结论照常返回，不阻塞

## 五、重要提醒

### 已知的坑（明天注意）

1. **Hermes 终端输出会截断长字符串**
   - 涉及 token/长字符串时，务必用 `subprocess` 直接读写文件
   - 或 `curl -o file` 再读文件

2. **curl 命令必须单行**
   - 多行 f-string 会把 `-o` 参数切断

3. **WSL 从 /mnt/d 读图慢 8 倍**
   - 训练前把数据复制到 `~/skin_cancer_data/`
   - 用完可删（原始数据在 D 盘）

4. **皮肤镜图像禁用垂直翻转/旋转的 TTA**
   - 会破坏解剖方位感

5. **集成后必须重新调阈值**
   - 任何改变输出分布的改动都要重新校准
