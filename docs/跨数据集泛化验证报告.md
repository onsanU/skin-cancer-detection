## 三、结论

1. **泛化落差 = -11.87 个百分点**（BCN 平衡集最优 acc − HAM 测试集 acc）
   → 落差明显，模型存在较强的**域依赖**，跨医院数据泛化不足。
2. **AUC 落差相对小**：HAM 0.9276 → BCN 0.8214（−0.1062），
   说明模型的**排序/区分能力**在跨域后保留了一部分，主要损失来自**阈值漂移**
   （BCN 最优阈值 0.45~0.51，与 HAM 标定的 0.48 接近，但准确率整体下移）。
3. **误报增加是主要错误模式**：BCN 全量集 FP=1317（良性侧误报多），
   与 BCN20000 专收「低色素难样本 + 指甲/黏膜部位」的数据特性吻合。
4. **价值**：这次验证回答了一个关键问题——「86.38% 到底是通用病变特征还是 HAM 域特征？」
   答案是**两者都有，且域特征占比不小**。这是后续引入混训数据最有力的动机。
