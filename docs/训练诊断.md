# 训练问题诊断与优化方案

## 第一轮结果（基线）

| 指标 | 训练集 | 测试集 |
|------|--------|--------|
| 准确率 | 98.86% | 79.34% |
| Loss | 0.053 | 1.052 |
| 恶性Recall | 99.55% | 83.90% |

**结论：严重过拟合**（差距 19.5%）

## 根因分析

1. **数据量太小**：train 只有 792 张，ResNet50 有 2500万参数
   → 模型"背下了"训练集，泛化能力差

2. **学习率偏大**：head lr=1e-3 对 792 张小数据集太猛
   → 3 个 epoch 就冲到 85% 训练准确率，后面全是记答案

3. **backbone 学习率也不小**：1e-4 会破坏 ImageNet 预训练特征
   → 小数据集上，预训练特征很宝贵，不该大幅改动

4. **增强强度不够**：medium 对 792 张来说还是太温和

5. **没有正则化手段**：只有 dropout 0.3，没有 weight decay 调优

## 优化策略

### 方案A：保守微调（推荐先试）
```
--lr-head 3e-4          # 降3倍
--lr-backbone 1e-5      # 降10倍（保护预训练特征）
--aug strong            # 增强拉满
--dropout 0.5           # 加强
--weight-decay 1e-3     # 加重正则
--freeze-backbone       # 先冻结，只训头
```

### 方案B：ResNet101 + 大输入
考虑换更强 backbone + 更高分辨率

### 方案C：两阶段训练
先冻结 backbone 训头，再解冻微调

### 方案D：增加数据
不抽样，用全部 10015 张（但任务书要求350例，需权衡）
