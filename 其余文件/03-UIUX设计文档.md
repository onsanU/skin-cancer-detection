## 一、设计理念

### 1.1 核心原则

| 原则 | 体现 |
|------|------|
| **专业可信** | 医疗蓝主色调、克制的视觉元素、严谨的措辞 |
| **降低焦虑** | 柔和的圆角、充足留白、结果用中性表述而非恐吓 |
| **引导清晰** | 步骤编号 ①②③、明确的操作按钮、即时的状态反馈 |
| **安全合规** | 免责声明显著但不喧宾夺主，三处重复强化 |
| **无障碍** | 颜色 + 图标双重编码（不只靠红绿区分结果）|

### 1.2 用户心理考量

皮肤癌检测是**高焦虑场景**，用户可能正在担心自己的健康。设计上特别注意：

- ❌ 避免：大面积红色、警示图标、绝对化表述（"你患有"）
- ✅ 采用：柔和配色、中性动词（"倾向"、"建议"）、建设性行动指引
- ✅ 原则：**给结论，更给出路** —— 每个结果都配可执行的下一步

```javascript
// tailwind.config.js
colors: {
  medical: {          // 主色：医疗蓝（专业、可信）
```

| 属性 | 值 | 说明 |

### 2.4 阴影与动效

| 元素 | 阴影 | 说明 |
|------|------|------|
| 卡片 | `shadow-sm` | 极轻，避免厚重 |
| 卡片悬停 | `shadow-md` | 微提升 |
| 主按钮 | `shadow-sm` | — |
| 顶栏 | `shadow-sm` | 与内容分离 |

**动效规范**：

| 动效 | 时长 | 缓动 | 用途 |
|------|------|------|------|

**顶栏规范**：
- 高度 64px，`sticky top-0`，白色背景 + 底部细边框

### 3.2 首页（HomePage）

**区块 1：Hero 区**
- 背景：`linear-gradient(to-br, medical-600, medical-700, medical-900)` 深蓝渐变
- 内容：
  - 徽章："深度学习模型 · ResNet50 · 医疗影像分析" + 绿点脉冲动画
  - 主标题（2行）："皮肤病变图像 / 智能检测系统"
  - 描述：说明产品能力与定位
  - 主按钮："开始检测 →"（白底蓝字，`shadow-lg`）
  - 次按钮："注册账号"（透明底白边框，未登录时显示）

**区块 2：模型状态卡（4 宫格）**
- 半透明玻璃拟态：`bg-white/10 backdrop-blur` + 白边框
- 4 张卡片：
  | 卡片 | 内容 |
  |------|------|
  | 模型状态 | "已就绪" + 绿点 / "未就绪" + 黄点 + 架构名 |
  | 输入尺寸 | "224×224" + "RGB 图像" |
  | 平均推理 | "31.5ms" + "单张图像" |
  | 我的检测 | "12 次" + "恶性 5 / 良性 7"（未登录显示"未登录"）|

**区块 3：系统功能（6 卡片网格）**
- 3 列布局（移动端 1 列），每卡片含 emoji 图标 + 标题 + 描述
- hover 时 `shadow-md` + 边框变蓝
- 6 项：便捷上传 / AI 智能识别 / 可视化结果 / 健康建议 / 历史记录 / 数据安全

**区块 4：检测流程（4 步骤）**
- 白底区块，4 个圆形编号（①-④）+ 标题 + 说明
- 流程：上传图像 → 图像预处理 → 模型推理 → 结果解读

**区块 5：免责声明**
- 黄底警示卡（`bg-amber-50` + `border-amber-200`）
- 图标 ⚠️ + 标题 + 正文（关键要求加粗）

## 四、响应式设计

| 断点 | 宽度 | 主要变化 |
|------|------|---------|
| `md` 以下 | < 768px | 导航折叠为底部标签栏；检测页单列；历史 1 列；Hero 标题缩小 |
| `md` | ≥ 768px | 历史 2 列 |
| `lg` | ≥ 1024px | 检测页两列；历史 3 列 |
| 容器最大宽 | 1152px | `max-w-6xl mx-auto` |

**移动端优化**：
- 底部标签栏（3 个导航项，等宽，当前页蓝色下划线）
- 按钮增大到 44px 高度（易点击）
- 图片预览高度限制 `max-h-80`
- 字号在移动端适当缩小（`text-3xl` → `text-2xl`）

## 五、无障碍与可用性

| 措施 | 说明 |
|------|------|
| **双重编码** | 结果不只靠颜色区分，同时用图标（⚠/✓）和文字（"恶性"/"良性"）|
| **对比度** | 正文文字与背景对比度 > 4.5:1 |
| **焦点可见** | 输入框 `focus:ring-2 focus:ring-medical-500` |
| **语义化** | 使用 `header`/`main`/`footer`/`nav` 等语义标签 |
| **键盘可用** | 所有交互元素可 Tab 到达，按钮用 `<button>` 而非 `<div>` |
| **错误可读** | 错误提示为文字描述，不只靠颜色 |
| **加载状态** | 所有异步操作有明确加载指示 |
