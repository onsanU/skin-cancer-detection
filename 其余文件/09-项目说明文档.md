### 3.4 数据划分方法（关键）

**病灶级划分**：同一 `lesion_id` 的所有图片必须落在训练集或测试集的**同一侧**。

原因：HAM10000 中同一病灶可能有多张不同角度的照片。若按图片随机划分，同一病灶的图片可能一张进训练集、一张进测试集，导致模型"考前见过题"，准确率虚高但实际无用。

**验证结果**：
```
训练集病灶 560 / 测试集病灶 140
病灶级交集：0 ✅
图片级交集：0 ✅
```

### 4.5 阈值参数（三档工作模式）

**集成模式（默认，推荐阈值 0.48）**：

| 模式 | 阈值 | 准确率 | 恶性召回 | 漏诊率 | 适用场景 |

| 平衡模式 | **0.33** | 83.10% | 95.76% | 4.24% | 日常自检 |
| 精确模式 | **0.48** | **86.38%** | 91.53% | 8.47% | **默认** |

**单模型模式（回退方案，阈值 0.50）**：

| 模式 | 阈值 | 准确率 | 恶性召回 | 漏诊率 | 适用场景 |
|------|------|--------|---------|--------|---------|
| 筛查模式 | 0.20 | 78.87% | **99.15%** | 0.85% | 初步筛查（漏诊 1 张）|
| 平衡模式 | 0.33 | 83.10% | 95.76% | 4.24% | 日常自检 |
| 精确模式 | **0.48** | **86.38%** | 91.53% | 8.47% | 默认 |

**阈值确定方法**：
- 单模型：`src/threshold_tuning.py`，扫描 0.20~0.80（61 个操作点）
- 集成：`src/ensemble_threshold_tuning.py`，同样扫描 61 个操作点

**关键结论**：集成改变了概率分布，必须**重新确定阈值**——早期成员组合时从 0.50 重标到 0.51；换用当前成员（vE_r101_288 + mix_cutmix_long）后在验证集上再次标定为 **0.48**。
否则会出现"集成准确率反而低于单模型"的现象（早期实验中阈值 0.50 时集成 84.51% < 单模型 84.98%）。

## 五、训练实验记录

### 5.1 七组实验总览

| # | 实验 | 训练数据 | 架构 | 关键策略 | acc | AUC |
|---|------|---------|------|---------|-----|-----|
| 1 | 基线 | 792张 | R50/224 | medium增强 | 81.69% | 0.8552 |
| 2 | 方案A | 792张 | R50/224 | strong增强+保守lr | 81.69% | 0.8605 |
| 3 | **v2全量** | **9802张** | R50/224 | 数据扩容 | **84.98%** | 0.9163 |
| 4 | 实验C | 3672张 | R50/224 | 1:1平衡+超低lr | 80.75% | 0.8901 |
| 5 | 方案D | 9802张 | R50/224 | warmup+标签平滑 | 83.57% | 0.9146 |
| 6 | 方案E | 9802张 | R101/288 | 高清+大模型 | 84.98% | 0.9187 |
| 7 | **CutMix 数据混合** | 9476张 | ConvNeXt-T/288 | CutMix + 50轮长训练 | **85.92%** | — | 裂口 -17.96% → -9.01% |
| 8 | **★ 多模型集成** | 9476张 | R101/288 + ConvNeXt-CutMix | 加权平均 @0.48 | **86.38%** | **0.9276** | 当前生产方案 |

**本表列出主要实验：8 组二分类 + 1 组 7 类分类**（7类结果见 4.4 节）；加上学习率探索、阈值标定、TTA 验证等专项实验，累计 **11 轮完整调优**。

### 5.2 关键结论

| 结论 | 数据支撑 |
|------|---------|
| **数据量是最大瓶颈** | 792→9802张，acc +3.3%，AUC +6.1% |
| **单模型 AUC 天花板 ≈ 0.919** | 三个有效实验的 AUC 高度一致 |
| **集成可突破天花板** | AUC 0.9162 → **0.9287** |
| **集成必须重调阈值** | 早期成员：@0.5 时 84.51%，@0.51 时才 85.45%；当前成员沿用经验，重标为 **0.48** 后达 86.38% |
| **学习率存在两难区间** | 过大破坏预训练特征（epoch1即最佳），过小学不动（卡在80%）|
| **强行平衡分布反而有害** | 实验C 丢了 6000+ 良性样本，acc 降至 80.75% |
| **提高分辨率能提升 AUC** | R101/288 的 AUC 0.9187 > R50/224 的 0.9162 |
| **TTA 在本场景有害** | 皮肤镜图像有方向性，翻转/旋转破坏方位感 |
| **7 类瓶颈是样本量不是模型** | AUC 0.9258 很高但 acc 仅 74.32%，少数类样本太少 |

## 十二、复现指南

### 12.1 从零复现完整流程

```bash
PROJ="皮肤癌图像系统"
PY=python
cd "$PROJ"

# ① 数据准备（若已有 dataset/HAM10000_raw 可跳过下载）
#    下载：aria2c -x 8 "https://www.kaggle.com/api/v1/datasets/download/kmader/skin-cancer-mnist-ham10000"
cd data_scripts
python3 prepare_dataset.py                 # v1: 350病灶抽样
python3 prepare_dataset_v2.py              # v2: 全量扩容
cd ..

# ② 复制数据到本地盘（提速 8 倍）
cp -r dataset/processed_v2_full ~/skin_cancer_data/

# ③ 训练模型
$PY src/train_resnet50.py \
    --data ~/skin_cancer_data/processed_v2_full \
    --epochs 40 --bs 32 --aug medium \
    --lr-head 5e-4 --lr-backbone 5e-5 \
    --out models_reproduce

# ④ 阈值调优
$PY src/threshold_tuning.py --model models_reproduce/best.pt

# ⑤ 模型量化
$PY src/onnx_quantize.py --model models_reproduce/best.pt --calib 100

# ⑥ 启动服务
cd backend
nohup $PY -m uvicorn app.main:app --host 0.0.0.0 --port 8000 > /tmp/backend.log 2>&1 &

# ⑦ 构建前端
cd ../frontend && npm install && npm run build

# ⑧ 系统测试
cd .. && $PY scripts/system_test.py

# ⑨ 管理后台（v1.1.0：无需构建，启动后端即挂载）
#    验证：curl -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/admin/
#    测试：python3 /tmp/verify_admin_api.py
#    账号：admin / <密码>（首次部署会自动迁移建角色字段）
```

### 12.2 关键随机种子

| 环节 | 种子 | 说明 |
|------|------|------|
| 数据抽样 | 42 | `prepare_dataset.py --seed 42` |
| 训练 | 42 | `train_resnet50.py --seed 42` |

固定种子确保结果可复现。
