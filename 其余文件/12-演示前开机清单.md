## 救命锦囊

### ① 模型未就绪（ready=false）

```bash
# 查看具体错误
curl -s http://127.0.0.1:8000/api/health | python3 -c "
import json,sys; print(json.load(sys.stdin)['model']['load_error'])"

# 检查模型文件
ls -lh "models_compressed/model_int8.onnx"

# 若 ONNX 有问题，临时回退到 PyTorch 后端
# 编辑 backend/app/config.py，把 USE_ONNX 改为 False，然后重启服务
```

### ② 服务启动失败（端口被占用）

```bash
# 找占用进程
ss -tlnp | grep 8000

# 杀掉后重启
pkill -f "uvicorn app.main"; sleep 2
cd backend
nohup python -m uvicorn app.main:app \
    --host 0.0.0.0 --port 8000 > /tmp/skin_backend.log 2>&1 &
```

### ③ 前端页面 404

```bash
# 重新构建
cd frontend
npm run build
# 重启后端让它重新挂载
pkill -f "uvicorn app.main"; sleep 2
cd ../backend && nohup python -m uvicorn app.main:app \
    --host 0.0.0.0 --port 8000 > /tmp/skin_backend.log 2>&1 &
```

### ④ 演示时上传图片无反应

**不要慌，念兜底存档**：

> "系统当前网络略有波动，我这边有预先跑好的演示输出，我们可以看这个。"

打开 `演示存档/` 里的对应文件展示。

### ⑤ 演示时服务完全挂了

> "那我用预先准备的演示记录来说明结果。"

直接念 `演示存档/demo_output.txt`，内容包含完整的检测流程与结果。

### ⑥ 【v1.1.0】管理后台打不开（/admin/ 返回 404）

**原因**：后端启动时 `static/admin/` 目录尚未存在，静态挂载被跳过。

```bash
# 确认目录存在
ls -la "backend/static/admin/"

# 重启后端（挂载判定只在启动时执行一次）
pkill -f "uvicorn app.main"; sleep 2
cd backend
nohup python -m uvicorn app.main:app \
    --host 0.0.0.0 --port 8000 > /tmp/skin_backend.log 2>&1 &

# 重启后日志应有这一行
grep "已挂载管理后台" /tmp/skin_backend.log
```

### ⑦ 【v1.1.0】管理后台登录不进去

| 现象 | 原因 | 解决 |
|------|------|------|
| 提示"用户名或密码错误" | 密码不对 | 用 `admin` / `<密码>`（注意大小写）|
| 提示"该账号不是管理员" | 用了普通用户账号 | 换 admin 账号 |
| 登录成功但立刻跳回登录页 | 后端重启后 token 失效 | 重新登录 |

```bash
# 命令行确认管理员账号还在
cd backend
python -c "
import sys; sys.path.insert(0,'.')
from app import database
for r in database.get_conn().execute(\"SELECT id,username,role FROM users WHERE role='admin'\").fetchall():
    print(dict(r))
"
# 若无输出 → 用《07-部署运维手册》§4.3 的命令行方式重建管理员
```

### ⑧ 【v1.1.0】管理后台样式全无（白板页面）

**原因**：vendor 静态资源缺失或路径错误。

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  http://127.0.0.1:8000/admin/vendor/adminlte/css/adminlte.min.css
# 期望 200；若 404 → 检查 backend/static/admin/vendor/ 目录是否完整
```
